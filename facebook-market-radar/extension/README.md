# Extension unpacked — lưu thẻ vào Radar

Chrome Web Store listing **không** nằm trong Vòng 1. Gói này chỉ mở form Radar với URL tab Ad Library.

## Cài (unpacked)

1. Chrome → `chrome://extensions` → Developer mode → Load unpacked → chọn thư mục này.
2. Mở popup, điền origin Radar (`http://127.0.0.1:3100` hoặc VPS).
3. Đang xem `facebook.com/ads/library` → bấm **Mở form lưu thẻ**.

Extension **không** đọc DOM Facebook, không gọi Graph, không scrape.
